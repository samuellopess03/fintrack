# Changelog

Todas as mudanças relevantes do FinTrack são documentadas aqui.

O formato segue [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/)
e o projeto adere ao [Semantic Versioning](https://semver.org/lang/pt-BR/).

As seções de cada versão são:
- **Adicionado** — novas funcionalidades
- **Alterado** — mudanças em funcionalidades existentes
- **Corrigido** — correções de bug
- **Removido** — funcionalidades removidas
- **Segurança** — correções de vulnerabilidade
- **Depreciado** — funcionalidades que serão removidas em versões futuras
